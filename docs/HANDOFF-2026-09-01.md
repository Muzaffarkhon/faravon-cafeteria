## 1. Как поднять проект на новой машине

```bash
git clone <repo> && cd faravon-cafeteria
git pull                      # подтянуть все коммиты
npm install
cp .env.example .env          # заполнить (см. ниже); .env в .gitignore, между машинами не едет
```

### 1.1. База данных — два варианта

**A. Локальный Postgres в Docker (рекомендуется для разработки).**
В репозитории есть `docker-compose.yml` (контейнер `faravon_db`, `postgres:16-alpine`, порт **5433**, БД `faravon_cafeteria`, юзер/пароль `faravon`/`faravon`).

```bash
docker compose up -d
```

`.env`:
```
DATABASE_URL="postgresql://faravon:faravon@localhost:5433/faravon_cafeteria?schema=public"
SHADOW_DATABASE_URL="postgresql://faravon:faravon@localhost:5433/faravon_shadow?schema=public"
```

**B. Облачный Neon** (та же строка, что была на прошлой машине; бесплатный тариф «засыпает» через 5 мин — возможны холодные старты и редкие обрывы). Строка вида
`postgresql://<user>:<pass>@<host>-pooler.<region>.aws.neon.tech/neondb?sslmode=require&channel_binding=require`.

> Turso/Supabase рассматривались — Turso не подходит (в схеме Postgres-enum и поля-массивы), Supabase = эквивалент Neon без выгоды. Оставляем Postgres.

### 1.2. Миграции, сид, запуск

```bash
npx prisma migrate deploy      # применить все миграции (на пустой БД проверено — проходит)
npm run db:seed                # начальные справочники + демо-пользователи
npm run dev                    # http://localhost:3000
```

Если `db:seed` падает с FK-ошибкой по `benefitCard` — значит в БД уже есть заявки (`ApplicationItem`). Сначала `npm run flow:reset`, потом `npm run db:seed`. **Сид карточек/партнёров разрушающий (deleteMany + create) — на боевой БД запускается один раз.**

`prisma generate` держит DLL движка на Windows — если запущен `npm run dev` или `npm run bot`, `prisma generate` / `npm run build` упадут с `EPERM`. Останови их или запускай `npx next build` напрямую.

## 5. Рекомендуемый порядок работ

**До деплоя (код):**
1. bcrypt cost 10 → 12 (5 мест) — 15 минут.
2. Аудит logout + аудит изменения ролей (когда появится UI ролей).
3. Индикация просроченных позиций в `/review`.

**Блокеры MVP (крупные):**
4. UI управления пользователями/ролями + справочник сотрудников + деактивация (`users.manage` уже в матрице прав, роут нужен).
5. Импорт сотрудников из Excel (минимальный вариант источника данных §8) + сверка по табельному номеру + деактивация отсутствующих.
6. Фильтры/сортировка/пагинация + массовые действия в `/review`.

**Расхождения:**
7. Rate-limit по IP + CAPTCHA после превышения.
8. Оконные уведомления: «окно открыто» (всем), «закрывается через 3 дня, льготы не выбраны» (напоминание) — нужен планировщик/крон по периодам.
9. Экран активных сессий (список + сброс).
10. Загрузка картинок: лимит 2 МБ, поддержка SVG (с санитизацией!), антивирусная проверка, приватные ссылки.
11. Реестр купонов: фильтры по партнёру и сотруднику.
12. Прицельная проверка 360 px + прогон по WCAG 2.1 AA.

**Деплой (блок A, в дашборде Vercel — делает заказчик/владелец проекта):**
- Deployment Protection → Vercel Authentication = Disabled (иначе cron и внешние проверки получают 307).
- Env: 8 переменных из §1.3 (новые секреты, не из dev).
- Storage → Create → Blob (даст `BLOB_READ_WRITE_TOKEN`).
- После первого деплоя: `DATABASE_URL="<prod>" npx prisma migrate deploy`, затем один раз `npm run db:seed`, сменить пароль `superadmin`.
- Вернуть webhook: `npm run webhook`.
- Две Cronjob на cron-job.org, заголовок `Authorization: Bearer <CRON_SECRET>`:
  - `https://<домен>/api/cron/deliver-notifications` — каждую 1 мин
  - `https://<домен>/api/cron/sla-escalations` — каждые 10–15 мин
- Проверка версии: `curl -s https://<домен>/login | grep -o petal-drift`.

**Заказчик (вне кода):**
- Ответы на 12 вопросов Приложения А (критично — в. 1–3).
- Источник данных о сотрудниках, домен + TLS, Figma/брендбук, согласие на обработку ПДн.
- Согласующие и HR должны быть заведены как сотрудники и привязать бота (иначе уведомления им копятся в БД, но в Telegram не уходят).
- Настройка бэкапов БД (30 дней, RPO ≤ 24 ч, RTO ≤ 4 ч), размещение ПДн с учётом законодательства РТ.
