**Ветка Git:** `main`.
**Тесты и сборка:** `npm run typecheck` — 0 ошибок; `eslint .` — 0 ошибок.
**База данных:** Supabase (Mumbai) — та же, что и прод; `.env` переключён на неё в этой сессии, пароль сброшен и обновлён в Vercel.

## 1. Инфраструктура и обслуживание

1. **Локальный `.env` был на старом Neon** — переключён на Supabase (прод-БД, Mumbai) с новым паролем (старый засветился в переписке, сброшен через Supabase → Reset password). Пароль также обновлён в Vercel Env Variables пользователем.
2. **Локальный `main` отставал от `origin/main` на 34 коммита** — подтянут (`git pull --ff-only`), поставлены новые зависимости (`recharts` и др.), сгенерирован Prisma-клиент под новую миграцию `report_presets`.
3. **Vercel: 151 → 6 деплоев.** Аккаунт превысил бесплатный лимит Hobby (`Functions Storage` 44 ГБ / 10 ГБ — это накопительный счётчик ГБ-месяцев за расчётный период, он не откатывается назад чисткой, только останавливает дальнейший рост). Почистили командой `vercel remove faravon-cafeteria --safe --yes` (сохраняет деплои с активными алиасами). Проверено: все удалённые деплои были резервной копией уже смерженного в git кода — ничего не потеряно.
4. **Открытый PR [#3](https://github.com/Muzaffarkhon/faravon-cafeteria/pull/3)** (`feat/mobile-touch-targets`, с 3 сентября) — код устарел (написан до редизайна `(app)`-шелла с сайдбара на вкладки), но сама идея (тач-таргеты 44pt + доступность «Главной» всем ролям) была актуальна — переприменена заново поверх текущего кода (см. ниже), а не смерджена напрямую.
5. Локальный `cron`-джоб на переочистку Vercel-деплоев раз в 3 дня — **не сохранился** между сессиями (сессионный, до 7 дней максимум). Если нужно на постоянку — обсуждали вариант с облачной задачей (`/schedule`) на отдельном Vercel API-токене.

## 2. Правки вёрстки и UX

1. **Тач-таргеты HIG 44pt** — [ui.tsx](../src/components/ui.tsx) (`Button` sm/md 32/40 → 36/44px), кнопки меню/закрыть/профиль в [(admin)/_shell.tsx](../src/app/(admin)/_shell.tsx) и [(app)/_shell.tsx](../src/app/(app)/_shell.tsx) до 44×44, вкладки верхней навигации получили `min-h-11`.
2. **Спиннер загрузки маршрута** ([route-loading-spinner.tsx](../src/components/route-loading-spinner.tsx)) — раньше измерял `<main>` через JS и центрировал `fixed`-портал; во время перехода `<main>` на миг пустел (высота мерилась как 0), спиннер прилипал к шапке. Переписан на обычный блок в потоке с `min-height` через инлайн-стиль (Tailwind-класс `min-h-[60dvh]` не попадал в собранный CSS — механизм сборки в этом дев-окружении не всегда подхватывает arbitrary-value классы, инлайн-стиль надёжнее).
3. **Мобильная шапка (app-шелл)** — скрыт дублирующий ряд вкладок сверху на мобильном (уже есть внизу), освобождено место для счётчиков/языка/профиля.
4. **Аудит** ([audit/page.tsx](../src/app/(admin)/admin/audit/page.tsx)) — сырые cuid в колонке «Объект» заменены на логин/ФИО/название (для User/Employee/Partner — это почти все строки лога). Колонка «Изменение» — разобрались, не баг: пустая только там, где реально нечего показывать (вход/выход).
5. **Отчёты** ([reports/page.tsx](../src/app/(admin)/admin/reports/page.tsx)) — по умолчанию открывался ближайший по дате период (обычно свежесозданный черновик следующего месяца, «Нет данных»); теперь по умолчанию выбирается открытый (`OPEN`) период.
6. **Графики по подразделениям/партнёрам** ([charts.tsx](../src/components/charts.tsx)) — подписи обрезались до 12 символов; лимит поднят до 20, для повёрнутых подписей график выше (`h-80` вместо `h-64`).
7. **Такси-промокод** ([flex-selection.tsx](../src/app/(app)/_components/flex-selection.tsx)) — при клике «Выбрать · указать номер» в конце страницы поле номера открывалось за пределами экрана и терялось; добавлен автоскролл (`scrollIntoView`) к полю при появлении.

## 3. Новая фича — лайки на льготы

- Модель `CardLike` (`prisma/schema.prisma`, миграция `20260917073624_add_card_like`) — сотрудник + карточка, уникальная пара, не привязано к периоду.
- `toggleLike(cardId)` в [actions.ts](../src/app/(app)/actions.ts).
- Иконка-сердце со счётчиком на карточках витрины ([flex-selection.tsx](../src/app/(app)/_components/flex-selection.tsx)) — оптимistичный отклик (не ждёт round-trip до Supabase в Мумбаи).
