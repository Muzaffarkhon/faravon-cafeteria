## 1. Поднять проект на новой машине

```bash
git clone https://github.com/Muzaffarkhon/faravon-cafeteria.git
cd faravon-cafeteria
git checkout feat/admin-banners
git pull
npm install
cp .env.example .env        # заполнить, см. §3; .env в .gitignore, между машинами не едет
docker compose up -d        # локальный Postgres (контейнер faravon_db, порт 5433)
npx prisma migrate deploy   # применить все 8 миграций
npm run db:seed             # справочники + демо-пользователи
npm run dev                 # http://localhost:3000
```

- Если `db:seed` падает с FK по `benefitCard` — в БД уже есть заявки. Сначала `npm run flow:reset`, потом `npm run db:seed`.
- `npm run build` / `prisma generate` на Windows падают с `EPERM`, если запущен `npm run dev` или `npm run bot` (держат DLL движка). Останови их или запускай `npx next build` напрямую.
- `prisma migrate dev` в этой среде интерактивен и не работает при предупреждениях — создавай файл миграции руками (см. `20260902021331_*/migration.sql` как образец) и применяй `prisma migrate deploy`.

## 5. Что сделано в этой сессии (коммиты `f0546ba` → `5bf4f46`)

### Редизайн (проходы 1–8, `f0546ba`…`eaff374`)
- **`src/components/ui.tsx`** — примитив `Button` переписан (варианты primary/secondary/soft/ghost/danger/success, размеры sm/md/lg, `loading` со спиннером, `fullWidth`, тактильное нажатие, состояния); `PageHeader` крупнее; инпуты `text-base` на мобильных (iOS-зум); убран мёртвый `.fc-*`.
- **Дашборд** (`(app)/page.tsx`): кнопки вместо строк-списков; «Витрина заботы» — крупные карточки с картинкой в «размытой рамке»; «Программы признания» крупнее; **корзина подтверждения** (fixed снизу справа) + прогресс-бар + галочка на выбранной; мини-навигация в сайдбаре; sticky-сайдбар с `lg`.
- **Экраны**: `/applications`, `/login`, `/change-password`, `/profile`, `/coupons` — переведены на новый язык; заголовки админки унифицированы (28px); `/admin/advertising-requests` и `/admin/partner-banners` из сырых прототипов → нормальный вид; `/admin/reports` — метрики с полосой-индикатором, топы бар-листами; формы админки — кнопки `loading`.
- Метод: `fe-design`/`web-interface-guidelines`/`taste-skill` из репозиториев заказчика на GitHub. Бренд «Фаровон» (красный OKLCH, системный шрифт, лепестки) сохранён.

### Билборд партнёров (`9f25a76`)
Промо-баннер сотрудника на дашборде: полноширинный (`h-56`), фото + градиентный скрим, чип «ПАРТНЁР», заголовок, CTA. Управление — `/admin/partner-banners`.

### Процесс подрядчика + безопасность API (`2b33acf`, `daa74b2`)
- **`/provider`** — экран подрядчика: поиск купона по номеру → карточка (сотрудник, льгота, партнёр, срок) → «Погасить купон» (двухшаговое подтверждение). Пункт меню + плитка на дашборде для `coupons.confirm`.
- `src/lib/coupon.ts`: `lookupCouponByNumber`, `redeemCouponByNumber` (ISSUED→USED, аудит `COUPON_REDEEMED_BY_PROVIDER`, уведомление сотруднику).
- Шаблон уведомления `COUPON_CONFIRMED_BY_PROVIDER` (раньше слал сырую строку).
- **`src/lib/api-guard.ts`** — `apiGuard(permission)` → 401/403.
- **Закрыты дыры**: `/api/advertising/admin` (был без авторизации — отдавал все заявки с телефонами; `POST` давал одобрять) → `cards.manage`; `/api/partner-banner` (был открыт CRUD) → `partners.manage`.

### Купоны: QR + сканер (`4a3cf45`, `d1e08c1`)
- **`src/lib/qr.ts`** (`couponQrSvg`) — SVG QR на сервере, без клиентского JS.
- `/applications`: у действующих (ISSUED, не просроченных) купонов рядом с номером — QR.
- **`(app)/provider/_scanner.tsx`**: в Telegram Mini App — нативный `Telegram.WebApp.showScanQrPopup`; в обычном браузере — `getUserMedia` + `jsqr`. Deep-link `?number=…` тоже понимается.

### Купоны: защита от злоупотреблений (`d834207`, `cd72785`)
- **Двойное гашение/выдача** (гонка): атомарный `updateMany` с условием статуса в WHERE — выигрывает один запрос.
- **Просроченный купон**: `isCouponExpired`; гашение просроченного → перевод в `EXPIRED` + аудит `COUPON_EXPIRED` + отказ; у просроченного скрыт QR.

### Пароли (`ffd54cd`)
bcrypt cost **12** везде; timing-выравнивание входа (фиктивный `bcrypt.compare` при неизвестном логине); демо-подсказка `Password1` на `/login` скрыта при `NODE_ENV=production`.

### Telegram Mini App / мобильные (`d1e08c1`)
- **`src/components/telegram-chrome.tsx`** + `telegram-web-app.js` в root-layout: читает `safeAreaInset`/`contentSafeAreaInset` в CSS-переменную `--tg-top`; шапка приложения и экраны входа получают `paddingTop` — кнопки Telegram «Закрыть»/меню больше не перекрывают шапку. Вне Telegram `--tg-top = 0`.
- Инпуты `text-base` на мобильных — iOS больше не зумит страницу при фокусе.

### Одна льгота — раз в период + групповые льготы (`5bf4f46`)
- **`@@unique([applicationId, cardId])`** на `ApplicationItem` — одну льготу нельзя выбрать дважды за период. `toggleSelection`: повторный выбор карточки с не-DRAFT позицией → понятная ошибка. Во flex-карточке — «Уже выбрано в этом периоде · <статус>» вместо кнопки.
- **`BenefitCard.minParticipants`** (1 = без порога) — поле в форме карточки, в снимке версий/истории. `lib/selection.ts`: `groupProgress` / `groupProgressOne` (сколько сотрудников подтвердили льготу в периоде — статусы PENDING/APPROVED/COUPON_*).
- `issueCoupon`: купон **нельзя выдать**, пока группа не набралась.
- Flex-карточка и `/applications`: прогресс-бар «Групповая скидка N/M», активна при N ≥ M.
- Миграция `20260902021331_card_min_participants_and_item_unique` — применена локально И на проде (дубликатов `ApplicationItem` на проде 0, unique-индекс лёг чисто).
